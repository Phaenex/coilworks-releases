# Coilworks downloads

Coilworks is a free PLC trainer. Write ladder logic, run it on a real scan engine, and watch a 3D
machine react to it.

**[Download the latest release](https://github.com/Phaenex/coilworks-releases/releases/latest)**

- `Coilworks-<version>-x64.exe` is the installer for most Windows PCs.
- `Coilworks-<version>-arm64.exe` is for Windows on ARM.
- `Coilworks-<version>-x64-portable.exe` runs without installing.

This repository holds release downloads only. Coilworks is freeware: free to use, including in
classrooms and training, but not open source. See [LICENSE](LICENSE).
